# 心音检测策略实现

## 实现日期
2026-02-01

## 概述
为 Wavitor 添加了专门针对心音音频的检测策略，能够识别心脏跳动（S1 和 S2 心音）并准确计算心率。

## 心音特点

### 生理学特征
- **S1 心音（第一心音）**："lub" 声
  - 由房室瓣关闭产生
  - 通常较响亮
  - 持续时间：0.09-0.12 秒
  
- **S2 心音（第二心音）**："dub" 声
  - 由主动脉瓣和肺动脉瓣关闭产生
  - 音调较高
  - 持续时间：0.06-0.08 秒

- **S1-S2 间隔**：收缩期（0.02-0.15 秒）
- **S2-S1 间隔**：舒张期（较长）

### 信号特征
- **频率范围**：20-200 Hz（主要能量在 20-100 Hz）
- **波形**：短促的瞬态信号
- **规律性**：高度规律的周期性
- **心率范围**：40-200 BPM
  - 正常成人：60-100 BPM
  - 运动员：可低至 40-50 BPM
  - 儿童：较高，可达 120-140 BPM

## 算法设计

### 检测流程

```
原始心音信号
    ↓
低通滤波 (200 Hz)
    ↓
高分辨率 Onset 检测 (5ms hop)
    ↓
S1/S2 配对识别
    ↓
心跳提取
    ↓
节拍验证与清理
    ↓
心率计算
```

### 核心算法

#### 1. 低通滤波 (`applyLowPassFilter`)
**目的**：保留心音频率范围，去除高频噪声

**实现**：简单的 RC 低通滤波器
```typescript
cutoffFreq = 200 Hz  // 心音主要能量范围
RC = 1 / (2π × cutoffFreq)
alpha = dt / (RC + dt)
filtered[i] = filtered[i-1] + alpha × (data[i] - filtered[i-1])
```

**优势**：
- 计算效率高
- 保留心音特征
- 减少高频干扰

#### 2. 高分辨率 Onset 检测 (`detectHeartSoundOnsets`)
**关键参数**：
- **Hop Size**: 5ms（vs 音乐的 10ms）
- **Window Size**: 10ms（vs 音乐的 40ms）
- **阈值窗口**: 300ms（vs 音乐的 500ms）

**峰值检测**：
- 更严格的局部最大值判定（检查前后各 2 帧）
- 允许更短的间隔以捕获 S1-S2 对
- 自适应阈值（multiplier = 0.5）

**特点**：
- 更高的时间分辨率
- 能够区分 S1 和 S2
- 减少漏检

#### 3. S1/S2 配对 (`extractHeartBeats`)
**配对策略**：
```typescript
maxS1S2Gap = 0.15 秒  // S1-S2 典型间隔

for each onset:
  if (下一个 onset 在 0.15 秒内):
    识别为 S1-S2 对
    使用 S1 作为心跳标记
    跳过两个 onset
  else:
    作为单独心跳处理
```

**优势**：
- 识别完整的心动周期
- 使用 S1 作为主要标记（更稳定）
- 处理不完整的心音记录

#### 4. 节拍验证 (`validateHeartBeats`)
**验证规则**：
1. 间隔必须在 `[minInterval, maxInterval]` 范围内
2. 与中位数间隔的偏差 < 50%
3. 过滤异常值

**目的**：
- 去除误检
- 提高心率准确性
- 保证节拍规律性

#### 5. 置信度计算 (`calculateHeartSoundConfidence`)
**评分标准**：
```typescript
regularityScore = (偏差 < 15% 的节拍数) / 总节拍数
deviationScore = 1 - 平均偏差

confidence = regularityScore × 0.7 + deviationScore × 0.3
```

**特点**：
- 更重视规律性（70%）
- 心音应该比音乐更规律
- 偏差容限更严格（15% vs 音乐的 20%）

## 技术对比

### 心音检测 vs 音乐检测

| 特性 | 音乐检测 | 心音检测 | 原因 |
|------|---------|---------|------|
| **Hop Size** | 10ms | 5ms | 需要更高时间分辨率 |
| **Window Size** | 40ms | 10ms | 心音更短促 |
| **滤波** | 无 | 200Hz 低通 | 心音频率较低 |
| **峰值检测** | ±1 帧 | ±2 帧 | 更严格的局部最大值 |
| **配对识别** | 无 | S1-S2 配对 | 识别心动周期 |
| **规律性要求** | 20% 容差 | 15% 容差 | 心跳更规律 |
| **置信度权重** | 均衡 | 重规律性 | 心率应高度规律 |

## 使用场景

### 适用场景 ✅
1. **心音听诊录音**
   - 医学听诊器录音
   - 电子听诊器数据
   - 心音教学音频

2. **心率监测**
   - 胎心监测
   - 运动心率追踪
   - 心脏健康评估

3. **医疗研究**
   - 心音分析研究
   - 心律失常检测
   - 心音特征提取

### 不适用场景 ❌
1. 普通音乐
2. 节奏打击乐
3. 语音录音
4. 环境噪声

## 性能特点

### 优势
- ✅ **高精度**：针对心音优化，识别准确
- ✅ **S1/S2 识别**：能够区分两种心音
- ✅ **规律性检测**：对不规则心律敏感
- ✅ **噪声抑制**：低通滤波减少干扰
- ✅ **高分辨率**：5ms 精度

### 局限性
- ⚠️ **计算开销较大**：更密集的采样
- ⚠️ **对噪声敏感**：需要较清晰的心音信号
- ⚠️ **不适合音乐**：会误识别音乐节拍

## 测试建议

### 测试数据
1. **正常心音**
   - 静息状态心音（60-80 BPM）
   - 运动后心音（100-140 BPM）
   - 不同体位心音

2. **特殊情况**
   - 心动过缓（< 60 BPM）
   - 心动过速（> 100 BPM）
   - 心律不齐
   - 杂音存在

3. **录音质量**
   - 高质量专业录音
   - 低质量环境录音
   - 带背景噪声的录音

### 评估指标
1. **准确性**：与实际心率对比
2. **完整性**：漏检率
3. **误报率**：错误检测率
4. **置信度**：算法给出的可信度

### 验证方法
```
1. 上传心音音频
2. 选择"心音"检测策略
3. 观察检测结果
4. 检查控制台日志：
   - onset 候选数量
   - 提取的心跳数量
   - 最终验证的心跳数量
5. 对比波形图上的标记与听感
```

心音检测策略为 Wavitor 带来了医疗音频分析能力，填补了现有音乐检测算法在生理信号处理方面的空白。通过专门针对心音特征的优化，该策略能够准确识别心跳并计算心率，为医学教育和研究提供了有价值的工具。
