# 工作区存储功能使用指南

## 快速开始

### 1. 上传音频文件
1. 打开 Wavitor 应用
2. 点击或拖拽上传音频文件
3. 音频文件会自动保存到浏览器存储
4. 创建一个新的工作区

### 2. 编辑节拍
1. 在波形图上添加或删除节拍点
2. 所有操作自动保存
3. 支持撤销/重做功能

### 3. 切换工作区
1. 在左侧工作区列表中查看所有工作区
2. 点击任意工作区切换
3. 音频文件和节拍数据会自动加载
4. 当前工作区显示"当前"标签

### 4. 删除工作区
1. 鼠标悬停在工作区上
2. 点击右侧的垃圾桶图标
3. 确认删除（会同时删除音频文件和节拍数据）

### 5. 查看存储空间
- 在工作区列表底部查看存储使用情况
- 显示已用空间 / 总空间
- 显示使用百分比

## 功能特点

✅ **自动保存**: 所有操作自动保存，无需手动操作
✅ **大文件支持**: 可存储几十到几百 MB 的音频文件
✅ **完整历史**: 保存所有编辑历史，支持撤销/重做
✅ **快速切换**: 在多个工作区间快速切换
✅ **持久化存储**: 关闭浏览器后数据依然保留
✅ **空间管理**: 实时显示存储使用情况

## 数据说明

### 存储位置
- 数据存储在浏览器的 IndexedDB 中
- 数据库名称: `wavitor_db`
- 每个域名独立存储

### 数据内容
- 完整的音频文件（原始格式）
- 手动添加的节拍点
- 删除的检测节拍点
- 所有编辑历史记录
- 工作区元数据（文件名、创建时间等）

### 数据安全
- 数据只存储在本地浏览器
- 不会上传到服务器
- 只有当前域名可以访问
- 用户可以随时清除数据

## 注意事项

⚠️ **隐私模式**: 在无痕/隐私浏览模式下，数据可能在关闭浏览器后被清除

⚠️ **浏览器存储**: 用户可以在浏览器设置中清除站点数据，这会删除所有工作区

⚠️ **存储限制**: 不同浏览器有不同的存储容量限制，建议及时清理不需要的工作区

⚠️ **跨设备**: 数据只存储在当前设备的浏览器中，不会自动同步到其他设备

## 故障排查

### 问题 1: 无法加载工作区
**可能原因**: 音频文件已被删除或存储空间不足
**解决方法**: 
- 检查存储空间使用情况
- 尝试删除不需要的工作区
- 重新上传音频文件

### 问题 2: 存储空间不足
**解决方法**:
- 删除不需要的工作区
- 点击"清空所有工作区"（会删除所有数据）
- 清理浏览器缓存和数据

### 问题 3: 数据丢失
**可能原因**: 
- 浏览器设置自动清理
- 在隐私模式下使用
- 手动清除了浏览器数据

**预防方法**:
- 重要数据导出为 JSON 文件保存
- 避免在隐私模式下使用
- 检查浏览器自动清理设置

## 最佳实践

1. **定期清理**: 删除不再需要的工作区，释放存储空间
2. **备份重要数据**: 使用导出功能保存重要的节拍数据
3. **监控存储**: 关注存储空间使用情况，避免存满
4. **命名规范**: 使用清晰的文件名，方便识别工作区
5. **及时保存**: 虽然自动保存，但重要操作后检查是否正确保存

## 技术细节

- **存储技术**: IndexedDB
- **数据格式**: Blob (音频), JSON (元数据)
- **容量**: 通常 ≥ 50MB，部分浏览器可达 GB 级别
- **性能**: 异步操作，不阻塞 UI
- **兼容性**: 支持所有现代浏览器
